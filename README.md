SpiderEmbodiment 🕷️

A Virtual Reality Environment for Studying Embodiment, Presence, and Anxiety

🔬 Project Description

SpiderEmbodiment is a Unity-based Virtual Reality project in which users control a spider avatar and navigate through obstacle-based tasks.
The project is developed as a research tool for studying embodiment, presence, head rotation behavior, and experienced anxiety in immersive VR environments.

The core idea is to induce a strong sense of body ownership over a non-human avatar and to observe behavioral and emotional responses during interaction.

⚠️ Work in progress: The project is under active development. Code structure and assets may change.
